# 🏥 City Care Hospital Management System

A simple hospital management web application built with Python and Streamlit.

## Features

- Patient registration and search
- Doctor directory management
- Appointment booking
- Appointment status updates
- Dashboard with hospital statistics
- CSV-based data storage

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Community Cloud

1. Push this repository to GitHub.
2. Go to https://share.streamlit.io
3. Sign in with GitHub.
4. Click **New app**.
5. Select this repository, branch `main`, and main file `app.py`.
6. Click **Deploy**.

## Files

- `app.py` — Streamlit application
- `requirements.txt` — Python dependencies
- `data/` — Automatically created CSV data storage
